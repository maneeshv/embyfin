# TV Series Implementation Plan

> **For agentic workers:** Use subagent-driven-development for the independent backend and UI tasks, then verify the integrated application.

**Goal:** Browse and play local TV series by show, season and episode with optional TMDB metadata and episode-aware subtitles.

**Architecture:** Every original remains a video. Libraries opt into `videos`, `movies`, or `tv`; revision-bound episode matches add show and episode metadata. Grouped pages contain only available files the current account may access. Reuse the native player, TMDB HTTP bounds, cast links, and subtitle storage.

**Constraints:** No new dependencies, source writes, deployments, or edits to existing migrations. Preserve the existing movie changes. Automatic matching needs an explicit single episode number and a unique exact show title/year match; no guessing on ambiguous names or multi-episode files. Owner correction is supported. Missing metadata/subtitles never prevent original playback.

Tables: tv_shows(id,name,search_name,first_air_date,overview,genres,poster_path,backdrop_path,updated_at); tv_episodes(id,show_id,season_number,episode_number,name,search_name,overview,air_date,runtime,still_path,updated_at); tv_cast(episode_id,person_id,name,character,profile_path,position); episode_matches(video_id,revision,episode_id,state,checked_at).

API contract:

- GET /api/shows?q=&library=&offset=&limit= returns {items:[{id,name,year,overview,poster,backdrop,episodeCount,seasonCount}],total,offset,limit}.
- GET /api/shows/:id?season=&offset=&limit= returns {show,cast,seasons:[{number,episodeCount}],items:[publicVideo],total,offset,limit}. Show/season counts include only authorized available matches.
- GET /api/videos/:id/episode returns {match,show,episode,cast,previous,next}; adjacent episodes are {id,title,seasonNumber,episodeNumber} or null, restricted to authorized files in that show.
- GET /api/videos/:id/episode/search?q=&year= returns {items:[{id,title,year,overview}]}.
- POST /api/videos/:id/episode takes {tmdbId,season,episode,revision}, {auto:true,revision}, or {tmdbId:null,revision}; only the owner can mutate.
- GET /api/videos/:id/tv-artwork/:kind?person= supports poster, backdrop, still, person with the same access and bounded image rules as movies.
- publicVideo.episode is null or {id,showId,showName,showYear,seasonNumber,episodeNumber,title,overview,airDate,runtime,poster,backdrop,still}. Existing publicVideo.movie remains independent and optional; a video cannot match both.
